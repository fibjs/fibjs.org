# 模块 os_constants
[os](os.md) 模块常量定义模块

引用方法：

```JavaScript
var constants = require('os').constants
```

## 对象
        
### errno
**errno 错误码常量子对象**

```JavaScript
os_constants_errno os_constants.errno;
```

--------------------------
### signals
**信号常量子对象**

```JavaScript
os_constants_signals os_constants.signals;
```

--------------------------
### priority
**进程优先级常量子对象**

```JavaScript
os_constants_priority os_constants.priority;
```

--------------------------
### dlopen
**动态链接库加载标志常量子对象**

```JavaScript
os_constants_dlopen os_constants.dlopen;
```

## 常量
        
### UV_UDP_REUSEADDR
**UDP 地址重用标志**

```JavaScript
const os_constants.UV_UDP_REUSEADDR = 4;
```

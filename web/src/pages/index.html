Rapid Development

Rich built-in modules work out of the box. Write asynchronous code in a synchronous style without wrestling with complex async concepts, and build high-performance web services right away.

Outstanding Performance

Built on Google's V8 engine with high-performance C++ core components. Built-in multi-core support makes full use of server resources for maximum performance.

Community Friendly

Fully open source and compatible with npm package management. An active community plus rich documentation and examples keep your development flowing.

Simple and Easy to Use

Write asynchronous code the synchronous way: clear logic, easy to maintain.

fibjs uses a fiber model to avoid callback hell, making code as simple and natural as a synchronous program while keeping the high concurrency of asynchronous I/O.
